# Reto práctico: control de inventario

## Abrir la página

Abre `index.html` con Chrome, Edge, Firefox u otro navegador moderno. La página funciona como archivo local y no requiere instalación. El botón **Imprimir / guardar PDF** permite exportar la guía.

## Contenido

La guía describe un problema de inventario numérico para una cafetería, especifica entradas, validaciones, cálculos, resultados esperados, entregables y una rúbrica de 100 puntos. Los productos se identifican con códigos enteros; no se piden nombres ni se procesan cadenas de caracteres. Está pensada para Algoritmos y Programación I en C, con condicionales, ciclos, arreglos y asignación simple con `=`.
